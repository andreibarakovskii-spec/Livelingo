# LiveLingo v2 Business UX

## Bottom navigation
- Live — instant translation / conversation / meeting
- Meetings — history of recorded meetings
- Library — transcripts, exports, presentations
- Profile — languages, offline models, privacy, diagnostics

## Meeting live screen
- elapsed time and LIVE state
- original and translated transcript
- live insight cards: decisions, action items, risks, questions
- no TTS during meeting mode by default

## Meeting result screen
- title, duration, participants, languages
- short summary
- Decisions / Tasks / Risks / Questions
- full transcript with Original / Translation / Both switch
- actions: Ask meeting, Share, Export, Create presentation

## Ask meeting
Questions over a single meeting or workspace, e.g.:
- What did we decide about price?
- Who owns the next action?
- Which deadlines were mentioned?

## Presentation generator
Suggested outline generated from meeting data:
1. Goal and context
2. Key facts and metrics
3. Decisions
4. Risks / blockers
5. Action plan and owners
6. Next checkpoint

## Privacy
Default local-first mode. Clearly show when any optional cloud AI is enabled.
